Points vérifiés sans écart

  • Tokens : aucune valeur divergente entre les exports. Tokens YawREC conservés, hors --font-lcd, propre à YawREC.
  • Toutes les variables utilisées sont définies.
  • Contraste sur le fond opaque #1c1c1c : texte principal 14,95:1, secondaire 11,96:1, atténué 5,98:1, très atténué 4,81:1, rouge 4,53:1.
  • Pas de marque tierce affichée. PuTTY n'apparaît que pour nommer le format .ppk.
  • Aucun libellé anglais courant détecté (recherche par liste de mots).

Limites de ce contrôle

  • Lecture du code seulement : les maquettes n'ont pas été affichées, donc les débordements et l'alignement restent à contrôler sur l'application réelle.
  • Les ratios sur surfaces translucides sont calculés sur des fonds opaques équivalents.
  • L'import .ppk et le bureau distant VNC figurent dans les maquettes, mais leur faisabilité n'a pas été testée.
