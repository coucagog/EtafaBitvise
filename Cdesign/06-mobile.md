# Prompt 06 — Android

Adapte l'application à un téléphone Android, en portrait, largeur de référence 390 px, cibles tactiles de 48 px minimum.

Le flou de fond n'est pas garanti : utilise des surfaces opaques avec les mêmes tokens.

Écrans :
1. Liste de profils et formulaire de connexion
2. Vérification de clé d'hôte
3. Session : navigation basse Terminal, Fichiers, Tunnels, Journal
4. Terminal : rangée de touches Échap, Tab, Ctrl, Alt, flèches, au-dessus du clavier, sans masquer le curseur
5. Fichiers : un seul panneau, bascule Local / Distant, sélection par appui long, file des transferts dans un panneau bas
6. Tunnels : liste en cartes, ajout en plein écran
7. Notification permanente de session : nom du profil, nombre de tunnels, actions Afficher et Se déconnecter

Pas de bureau à distance sur mobile.
