# Prompt 01 — Extension du design system

Étends le design system joint avec une planche de composants, en gardant les tokens existants et en ajoutant seulement ceux qui manquent (espacements, rayons, surfaces) :

- onglets principaux et onglets de session fermables, avec pastille d'état
- boutons : primaire, secondaire, discret, danger, icône seule ; tailles compacte et normale
- champs texte, mot de passe, liste déroulante, case à cocher, interrupteur, champ port, chemin de fichier
- contrôle segmenté, `.kbd`, badges d'état, infobulle, menu contextuel
- tableau dense : tri, sélection multiple, redimensionnement de colonnes, ligne de progression
- séparateur de panneaux déplaçable, barre de progression, indicateur de débit
- boîtes de dialogue : confirmation, danger, formulaire
- notification et bannière persistante (exemple : reconnexion en cours)
- ligne de journal horodatée : info, avertissement, erreur

Montre pour chacun les états normal, survol, focus, actif, désactivé et erreur. Donne les variables CSS ajoutées.
