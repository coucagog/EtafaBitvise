Limites connues

  • L'agent de l'essai graphique est un agent de test sur tube nommé. L'agent OpenSSH de Windows est désactivé sur ce poste et Pageant n'a pas été essayé.
  • Export de la clé publique : vérifié par test unitaire ; la boîte d'enregistrement native n'a pas été pilotée. Import PEM et PKCS#8 : code présent, sans test dédié.
  • Le trousseau n'existe pas sur Android dans cette version (case absente) ; l'agent non plus. Linux et macOS : non essayés.
  • Clés privées sous Windows : le fichier hérite des droits du profil de l'utilisateur, sans restriction supplémentaire.
  • Import .ppk : non pris en charge.
