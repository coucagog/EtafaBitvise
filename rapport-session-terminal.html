Limites

  • Non exécuté : Android, Linux, macOS, serveur Bitvise.
  • Authentification par clé seule dans cet essai ; le mot de passe est couvert par le banc local.
  • Absents tant qu'ils ne sont pas réalisés : SFTP, tunnels, bureau distant, détachement d'onglet, reconnexion automatique avec compte à rebours.
  • Reconnexion : le mot de passe ou la passphrase restent en mémoire jusqu'à la déconnexion, jamais sur disque.
  • Fenêtre blanche observée une fois à 8 s du lancement, pendant une compilation, non reproduite ensuite. À surveiller.
  • La barre de défilement parasite des onglets est corrigée dans le code ; l'exécutable sera reconstruit à l'étape suivante.
