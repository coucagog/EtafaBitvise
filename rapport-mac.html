MLS Connect : version macOS

14 novembre 2026 · construite et lancée sur un iMac Pro Intel (Xeon W-2140B, 32 Go), macOS 15.7.3 · préparée le 11 novembre sans Mac

L'application compile sous macOS, son cœur passe tous les tests, et le paquet .dmg final est produit, universel (Mac Intel et Apple Silicon), avec mc-mcp. Lancée depuis ce paquet, l'application démarre et reste ouverte. Son interface n'a pas encore été regardée : je n'ai ni capture ni pilotage de la fenêtre sur le Mac. La partie Apple Silicon du paquet n'a jamais été lancée : il faudrait un Mac de ce type.

Erreur rencontrée à la première connexion

La première tentative a affiché « The key is encrypted ». La clé était protégée par une passphrase, qui n'avait pas été saisie : sur une nouvelle machine, le Keychain est vide. Une fois la passphrase saisie dans l'onglet Authentification, la connexion a réussi. Le message, repris tel quel de la bibliothèque SSH, a été remplacé par un texte en français qui indique où la saisir (commit a00b48d). Le paquet de livrables/macos/ date d'avant et affiche encore l'ancien détail.

Comment il a été construit

  • Tout est dans ~/mc-mac sur le Mac : sources, Rust, Node 22, tauri-cli. Supprimer ce dossier retire tout. Rien n'a été installé ailleurs ; les outils de ligne de commande d'Xcode étaient déjà présents.
  • Script mac.sh : vérification de l'interface, tests, node scripts/sidecar.mjs, puis cargo tauri build --config src-tauri/tauri.paquets.conf.json. Compilation finale : 2 minutes pour mc-mcp, 6 pour l'application.
  • Paquet universel, script mac-universel.sh : cible aarch64-apple-darwin ajoutée à Rust, mc-mcp compilé pour les deux architectures puis réuni par lipo, et cargo tauri build --target universal-apple-darwin. Environ 15 minutes.
  • Accès par SSH avec une clé créée pour cet essai, que vous avez autorisée vous-même sur le Mac.

Choix, inchangés

  • Pas de fenêtre transparente sur Mac : elle exigerait une API privée d'Apple, refusée sur le Mac App Store.
  • Barre de titre superposée : les trois boutons natifs remplacent les nôtres, le reste de notre barre est conservé.
  • Distribution sans alerte Gatekeeper : il faudra un certificat Developer ID et la notarisation.

À regarder sur le Mac

  • Position des trois boutons natifs face à notre barre de 32 px ; fond opaque, coins.
  • Icône de barre de menus (en couleur) et son menu : afficher, se connecter, quitter.
  • Raccourcis globaux Ctrl+Shift+F7 et F8 (touche Fn selon le clavier).
  • Une connexion réelle : empreinte, terminal, SFTP, sélecteurs de fichiers, copier-coller.
  • Mémorisation d'un mot de passe ou d'une passphrase dans le Keychain.
