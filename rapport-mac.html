MLS Connect : version macOS

11 novembre 2026 · préparée sans Mac · interface simulée dans la WebView de Windows

La version macOS est préparée : configuration propre au Mac, adaptation de l'interface, trousseau Keychain. Elle n'a jamais été compilée : il faut un Mac ou la CI GitHub, mise en attente. Le SDK d'Apple n'est licencié que sur matériel Apple, ce qui exclut une compilation croisée depuis Linux.

Choix

  • Pas de fenêtre transparente sur Mac : elle exigerait une API privée d'Apple, refusée sur le Mac App Store.
  • Barre de titre superposée : les trois boutons natifs remplacent les nôtres, le reste de notre barre est conservé.
  • Distribution hors App Store sans alerte Gatekeeper : un certificat Developer ID et la notarisation seront nécessaires. Sans eux, ouvrir l'application par clic droit puis « Ouvrir ».

À vérifier sur un Mac

  • Compilation, puis paquets .app et .dmg.
  • Position des boutons natifs face à notre barre de 32 px.
  • Icône de barre de menus (en couleur, pas en modèle monochrome).
  • Raccourcis globaux Ctrl+Shift+F7 et F8 (touche Fn selon le clavier).
  • Keychain, agent SSH, sélecteurs de fichiers, copier-coller dans les champs.
