MLS Connect : version Windows

14 novembre 2026 · Windows 11 Pro, WebView2 157.0.4341.60 · poste de développement

L'application Windows fonctionne et son installateur final est produit, avec mc-mcp. L'écran blanc apparu le 14 novembre ne venait ni du code ni de WebView2 : sur ce poste, un programme lancé depuis le dossier du projet tourne avec des droits réduits. Lancée depuis un autre dossier, l'application s'affiche normalement. L'installateur a été exécuté sur ce poste : installation, lancement, puis désinstallation sans reste.

Une copie de whoami.exe placée dans target\debug annonce « Niveau obligatoire faible »Windows lance en intégrité faible tout programme situé dans le projet

En intégrité faible, l'application ne peut écrire ni dans %TEMP% ni dans le cache WebView2 : la création de la vue échoue (0x800700AA avec le cache existant, 0x8000FFFF avec un cache neuf) et la fenêtre reste blanche. La même cause empêchait les tests d'écrire dans %TEMP%, et a fait échouer une première construction en mode final.

Ce qui a été fait

  • scripts\lancer.cmd copie l'exécutable de débogage vers %LOCALAPPDATA%\mls-connect-essai et le lance de là. scripts\lancer-inspection.cmd fait de même avec l'inspection WebView2 sur 127.0.0.1:9333.
  • Le garde-fou donne aux tests et aux constructions de paquets un dossier temporaire dans target.
  • L'application installée n'est pas concernée : elle ne vit pas dans le dossier du projet.

Installation pour le compte courant, dans %LOCALAPPDATA%\MLS Connect, avec mc-mcp.exe à côté de l'application. Non signé : Windows affichera un avertissement SmartScreen. Pour le refaire : scripts\attendre-et-tester.ps1 -Paquet -Final, environ 45 minutes sur ce poste.

À savoir

  • Ne lancez pas un exécutable depuis le dossier du projet : cargo run et cargo tauri dev donnent le même écran blanc. Passez par scripts\lancer.cmd.
  • L'étiquette du dossier n'a pas été retirée : le bac à sable la remettrait sans doute. La retirer reste votre décision.
  • La réinstallation de WebView2 faite pendant le diagnostic était inutile ; elle est sans effet sur le reste du poste.
