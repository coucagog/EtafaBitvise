MLS Connect : accès d'un agent

14 novembre 2026 · étude et prototype · essayé sur la VM 102 (Debian 13) ; approbation du niveau 2 essayée sous Windows

Un agent comme Claude Code peut se connecter à un serveur par MLS Connect, avec un profil que vous lui ouvrez et un niveau d'accès choisi. Il passe par mc-mcp, un serveur MCP qui réutilise le cœur de l'application. L'agent désigne le profil par son nom, sans jamais voir ni la clé ni la passphrase, et la clé d'hôte est vérifiée. Les niveaux 0 (lecture) et 3 (accès complet) sont essayés sur la VM 102 : tous les contrôles réussissent.

Utiliser l'accès

  1. Ouvrir une première fois la connexion dans MLS Connect, pour enregistrer la clé d'hôte. Mémoriser la passphrase dans le trousseau si la clé en a une.
  2. Dans le profil : Options, « Accès d'un agent », choisir le niveau.
  3. Déclarer le serveur MCP. mc-mcp est installé à côté de l'application (Windows : %LOCALAPPDATA%\MLS Connect\mc-mcp.exe ; Linux : /usr/bin/mc-mcp). Depuis les sources :
cargo build -p mc-mcp --release
claude mcp add mls-connect -- "C:\…\EtafaBitvise\target\release\mc-mcp.exe"

Ce qu'il faut savoir

  • La vraie limite reste le compte sur le serveur. Un agent qui a aussi un terminal sur le poste peut contourner un filtre local. Pour les niveaux 0 et 1, utilisez un compte dédié sans sudo et une clé limitée par restrict et from=.
  • Tout ce que l'agent lit part chez le fournisseur du modèle : n'ouvrez pas de dossiers contenant des secrets.
  • Au niveau 1, une commande ajoutée admet des arguments de plus. Terminez l'entrée par = pour l'interdire, et écrivez la commande entière dans sudoers.
  • Au niveau 2, MLS Connect doit être ouvert sur le même poste : chaque commande s'y affiche en entier, et rien n'est mémorisé. Sans réponse en 2 minutes, elle est refusée.
  • Au niveau 3, n'accordez pas à Claude Code d'autorisation permanente pour l'outil executer : il vous demandera alors votre accord à chaque commande.

Non fait

  • Niveau 2 : pas d'approbation sur Android ; aspect de la boîte non vérifié sous Linux (écran virtuel noir), ni sous macOS.
  • mc-mcp est inclus dans l'installateur Windows final (livrables/windows/, 4,2 Mo), exécuté sur ce poste : mc-mcp.exe est posé à côté de l'application et répond, puis la désinstallation le retire. Il est aussi dans les paquets Linux de livrables/linux, refaits et essayés sur la VM 102 (/usr/bin/mc-mcp pour le .deb). Paquet macOS : .dmg final construit sur un Mac Intel, avec mc-mcp dans l'application (livrables/macos/).
